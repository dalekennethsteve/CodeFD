The goal of this project is to explore the Lattice Boltzmann Method as a numerical
tool for simulating laminar fluid flow using various boundaries. This is achieved
by combining a theoretical study of the method with a practical numerical im
plementation in Python. Several benchmark flow configurations are investigated,
including Poiseuille flow and two-dimensional flow past a circular cylinder, rotat
ing cylinder, assembly of cylinders and squares, in order to assess the accuracy,
stability, and physical fidelity of the LBM in capturing key flow phenomena.
